XTREME MD

Connect any WhatsApp account using its phone number.

Include country code. Do not use +, spaces or the first 0.
Enter a number to generate its pairing code.
How to connect
1. Enter the number and generate the code.
2. Open WhatsApp → Linked devices.
3. Tap Link a device.
4. Choose Link with phone number instead.
5. Enter the displayed code.
The code expires shortly. Xtreme MD never asks for your OTP.
